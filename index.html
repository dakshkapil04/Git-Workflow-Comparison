INTERPRETATION

How to read the metrics

Merge conflicts

Count conflicts encountered during merges. Record only actual conflict events using the same counting rule in every experiment.

Integration time

Measure elapsed time from the first task commit until that task is successfully integrated into the shared target branch.

Commit frequency

Divide the number of meaningful commits by the number of developers and experiment days.

Collaboration efficiency

Use pull-request review time as a simple proxy. Also discuss hand-offs, review quality and coordination qualitatively.

Deployment failure rate

Failed deployment attempts divided by total deployment attempts, multiplied by 100. Define failure consistently.
